# ADR-0004：情感结论诚实化 + 云 LLM deny-by-default

- 状态：Accepted
- 日期：2026-09-08

## 背景（Context）

vault-grill 产品透镜评审指出两类风险：

1. **权威性幻觉与关系伤害**：SKEP/RoBERTa 的 0.85–0.92 准确率来自商品评论/微博基准，在情侣聊天域会**系统性误判反话、爱称、网络用语**（"行吧""呵呵""傻子（爱称）"）。初版引用的 **Gottman 5:1 积极消极比是方法误用**——其比值来自训练编码员对冲突互动视频的行为编码，不是全天文本极性分；Losada 2.9:1 早已被 Brown et al.(2013) 证伪。"军师建议/危险信号"这类 fluent prose + 引用 stats 的输出会被用户感知为权威诊断，焦虑期独自刷到或发给伴侣时可能造成真实伤害。报告还包含**对方**的私聊记录，分享涉及对方知情同意。
2. **隐私外发**：切云端 LLM API 时，采样文本含对方私密对话，对方从未同意发给第三方；正则脱敏抓不到昵称、爱称、共同经历等关系语境。

## 决策驱动

- 不假装模型输出是心理诊断；可解释、可回溯、可证伪优先于"看起来权威"。
- 隐私 fail-closed：默认不发送，发送范围由代码白名单硬约束，而非"脱敏后允许"的愿望。

## 考虑的选项

- **A. 维持权威包装**（输出"关系健康度/危险信号/军师建议"）：伪精确 + 误判 + 关系伤害风险，否决。
- **B. 保留指标但诚实化 + 免责 + 云 LLM deny-by-default（采用）**。
- **C. 砍掉一切关系/情感判定，只做中性描述统计**：最安全但丢失情感回顾的趣味与项目价值，否决。

## 决策（Decision）

采用 B：

- **命名诚实化**：Gottman 比值改名为"模型眼中的正负消息比（会误判反话/爱称，非关系诊断）"；"军师建议/危险信号"改为"值得聊聊的时刻 / 话题引子"，叙事段强制免责头。
- **固定免责面板**：报告与 Dashboard 均含"玩具级统计，非关系/心理诊断；反话、爱称会被误判；任何提示请当作话题引子而非结论；报告含对方聊天记录，分享前请征得对方同意"。
- 结论可回溯：LLM 叙事只做解读，每个量化结论必须引用 `stats.json` 字段；分层采样（起源/高情感波动/近 30 天），不喂全量。
- **云 LLM deny-by-default**：叙事 Provider 为 OpenAI 兼容接口，默认本地 Ollama；当 `provider=cloud` 时，代码层面**只允许发送数值型 stats 字段**（计数/比率/聚合时间戳），自由文本采样对云 provider 硬编码 local-only（字段白名单，非白名单字段根本不进请求体）；配置云 key 时启动日志大字警告数据出境。
- 模型版本进 `sentiment`/`daily_stats` 主键（`model_version`），词典版与模型版共存可对比、可回溯。

## 后果（Consequences）

- 正面：显著降低误导/关系伤害与隐私外发风险；结论更诚实、可复现；本地优先隐私卖点成立。
- 代价：结论"不权威"、娱乐性叙事更克制——这是面对模型域偏移与伦理风险的诚实取舍。
